# Accessibility fix to carry to OpenAlgo web (2026-11-25)

The brokerage calculator carried over from OpenAlgo web
(marketcalls/openalgo#2496, 4bce67c35) shows a profit in a green that is
below the contrast a large text needs in the light theme. The accessibility
scan (`e2e/accessibility.spec.ts`) now covers the two new sandbox pages,
`/sandbox/commissions` (the brokerage plan and the Transaction Costs tab) and
`/sandbox/calculator` with every card priced, in light and dark. Before the
fix the light calculator scan failed `color-contrast` on the four Net P&L
values of the Equities and F&O tab; dark passed. As decided on 2026-10-20,
the fix is made here and noted for the web. It is a class change.

Web line numbers are from the web checkout at `3f4c71e0f`; search for the
old text if they have moved.

## `frontend/src/lib/sandboxCharges.ts`

| Web line | Old | New | axe rule |
| --- | --- | --- | --- |
| 93 | `if (value > 0) return 'text-green-500'` (`pnlColor`, the calculator's Net P&L) | `if (value > 0) return 'text-green-700 dark:text-green-500'` | color-contrast |

The Net P&L is 20 px bold, so 3:1 is enough: green-500 measures about 2.3:1
on the white card, green-700 about 5.0:1. Red-500 (3.8:1) passes and stays.
In the dark theme green-500 passes and stays.
