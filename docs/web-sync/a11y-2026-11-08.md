# Accessibility fix to carry to OpenAlgo web (2026-11-08)

The Download page carried over from OpenAlgo web (d629f3d57, b592e914f) has
an `h1` ("Download OpenAlgo") and `h3` explainer titles ("Works like
OpenAlgo web", "Trading", "How to install", "Good to know"), with nothing
between them: each product's name is a `CardTitle`, which renders a `div`.
axe reports `heading-order` ("Heading levels should only increase by one")
on the first `h3`, and a screen reader's list of headings shows the
explainers without the product they belong to. As decided on 2026-10-20 for
shared accessibility defects, it is fixed here and noted for the web. The
edit is an attribute change; nothing changes on screen.

Web line numbers are from the web checkout at `a1b9e3250`; search for the
old text if they have moved.

## `frontend/src/pages/Download.tsx`

| Web line | Old | New | axe rule |
| --- | --- | --- | --- |
| 490 | `<CardTitle className="text-2xl">{product.name}</CardTitle>` (in `ProductDownloads`) | `<CardTitle className="text-2xl" role="heading" aria-level={2}>` | heading-order |

The test is `src/pages/Download.test.tsx` ("has no accessibility
violations"), which fails without the attributes.

## Desktop only (nothing to carry)
