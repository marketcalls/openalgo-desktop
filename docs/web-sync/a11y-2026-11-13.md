# Accessibility fix to carry to OpenAlgo web (2026-11-13)

The Alerts pages carried over from OpenAlgo web (marketcalls/openalgo#2435,
a455b2997) have status badges whose text is below 4.5:1 in the light theme.
The accessibility scan (`e2e/accessibility.spec.ts`) now covers `/alerts`
and `/slack` (the same page serves `/discord`) in light and dark, with a
channel in each state the badges show: on and ready, on and not ready, on
and needing setup, and off. As decided on 2026-10-20, the fix is made here
and noted for the web. Each edit is a class change.

Web line numbers are from the web checkout at `7ba5267f7`; search for the
old text if they have moved.

## `frontend/src/pages/alerts/AlertsIndex.tsx`

| Web line | Old | New | axe rule |
| --- | --- | --- | --- |
| 266 | `<Badge className="bg-green-600 text-white">` (Ready) | `<Badge className="bg-green-700 text-white">` | color-contrast |
| 273 | `<Badge variant="outline" className="border-amber-500 text-amber-600">` (Not ready, Needs setup) | `className="border-amber-500 text-amber-700 dark:text-amber-400"` | color-contrast |

## `frontend/src/pages/alerts/WebhookChannelSetup.tsx`

| Web line | Old | New | axe rule |
| --- | --- | --- | --- |
| 177 | `<Badge className="bg-green-600 text-white">On</Badge>` | `<Badge className="bg-green-700 text-white">On</Badge>` | color-contrast |

White on green-600 measures 3.3:1 and amber-600 on the white card 3.2:1;
green-700 and amber-700 measure 5.0:1. The amber badge keeps a light shade
in the dark theme, where amber-700 on the dark card would fall below 4.5:1.
