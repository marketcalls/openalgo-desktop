# Flow frontend: where the desktop departs from OpenAlgo web (2026-10-30)

OpenAlgo Desktop 1.0.5 carries the web's Flow frontend over from the web
checkout at `96e5927e5` (`frontend/src/{api/flow.ts,pages/flow,components/flow,
lib/flow,stores/flowWorkflowStore.ts,types/flow.ts}`), byte for byte and then
formatted by the desktop's Biome. This file lists every later edit to a
carried file, so that:

- a later web change can be carried over by diff, keeping these edits;
- the maintainer can apply the web defects and accessibility fixes upstream.

IDs are the 1.0.5 parity checklist's (`.lane/105/parity.md`). Web line
numbers are from `96e5927e5`; search for the old text if they have moved.
Desktop-only logic lives in its own files and is not listed line by line:
`src/lib/desktopFlow.ts`, `src/api/flowDesktop.ts`,
`src/components/desktop/{FlowWebhookReachability,FlowConfirmDialogs,
FlowLeaveGuard,FlowPanelNotes}.tsx`.
