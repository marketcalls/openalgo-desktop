last triage, `a1b9e3250`) up to `0b7427b38` (2026-11-17), oldest first, with
the desktop commit that carries it or the reason it is not carried. The
previous triage (`a9370edf8..a1b9e3250`) is in the message of desktop commit
`e8d91272`.
